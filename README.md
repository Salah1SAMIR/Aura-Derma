# 🌿 مشروع Aura Derma — موقع العناية بالبشرة الفاخر

مرحباً بك في مجلد المشروع الكامل لموقع **Aura Derma**. تم تنظيم هذا المجلد خصيصاً ليحتوي على كود المصدر (Source Code) والملفات المترجمة الجاهزة للتشغيل الفوري.

---

## 📁 هيكل المجلد والملفات (Directory Structure)

* 📂 **`src/`** — يحتوي على كود المصدر الرئيسي للموقع (React + JSX):
  * 📂 **`src/components/`** — مكونات واجهة المستخدم التفاعلية:
    * `Navbar.jsx` — شريط التنقل الزجاجي (Glassmorphism).
    * `Hero.jsx` — الواجهة الترحيبية وتصميم البداية الفاخر.
    * `ProductCatalog.jsx` — معرض المنتجات مع الفلاتر والبحث.
    * `ProductDetailModal.jsx` — نافذة تفاصيل المنتجات والنسب السريرية.
    * `TreatmentsSection.jsx` — معرض الخدمات العلاجية بالعيادة.
    * `BeforeAfterSlider.jsx` — شريط المقارنة التفاعلي قبل وبعد العلاج بالماوس/اللمس.
    * `BookingSystem.jsx` — نظام حجز المواعيد السريرية.
    * `CartDrawer.jsx` — سلة المشتريات التفاعلية مع دعم كود الخصم.
    * `ScienceSection.jsx` — قسم إثبات الفعالية السريرية وآراء الأطباء.
    * `Footer.jsx` — تذييل الصفحة مع نموذج الاشتراك ونقاط التواصل.
  * 📂 **`src/context/`** — لإدارة الحالة العامة (Global State) مثل السلة والنافذة المنبثقة.
  * 📂 **`src/data/`** — قواعد البيانات الثابتة بصيغة JSON للمنتجات والخدمات والمراجعات.
  * `App.jsx` — الملف الرئيسي لتجميع وتركيب الموقع.
  * `index.css` — ملف التنسيقات الرئيسي مع تهيئة Tailwind CSS v4.
  * `main.jsx` — نقطة انطلاق وتثبيت تطبيق React في المتصفح.

* 📂 **`dist/`** — **الموقع النهائي الجاهز للتشغيل الفوري**:
  * يحتوي على ملفات HTML و CSS و JS مضغوطة ومترجمة بالكامل.
  * تم ضبطها بمسارات نسبية لتشغيلها مباشرة من أي مكان أو رفعها فوراً على استضافة مجانية (GitHub Pages).

* 📄 **`package.json`** — ملف إدارة حزم ومكتبات المشروع.
* 📄 **`tailwind.config.js`** — إعدادات محرك Tailwind للتصميم والألوان المخصصة (Cream, Gold, Dark, Sage).
* 📄 **`vite.config.js`** — إعدادات محزم ومطور Vite.
* 📄 **`index.html`** — الصفحة الرئيسية الحاضنة للتطبيق مع تحسينات الـ SEO.

## 🚀 طريقة تشغيل المشروع للتطوير (Development)

إذا كنت ترغب في تشغيل المشروع والتعديل على الكود المصدري:

1. تأكد من تثبيت بيئة عمل **Node.js** على جهازك.
2. افتح مبدل الأوامر (Terminal) في مسار هذا المجلد.
3. قم بتثبيت الحزم البرمجية والمكتبات بكتابة الأمر التالي:
   ```bash
   npm install
   ```
4. قم بتشغيل خادم التطوير التفاعلي:
   ```bash
   npm run dev
   ```
5. افتح المتصفح على الرابط الموضح في الواجهة (غالباً `http://localhost:5173/`).

---

## 🛠️ بناء النسخة النهائية (Production Build)

إذا قمت بإجراء تعديلات على كود المصدر وتريد استخراج الملفات النهائية المحدثة لتشغيلها أو رفعها:
```bash
npm run build
```
سيقوم Vite بتحديث محتويات مجلد `dist` تلقائياً لتصبح جاهزة للنشر!
